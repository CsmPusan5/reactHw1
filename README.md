Мини-маркет — UI-кит и каталог на Vite + React + styled-components
Небольшой витринный проект и UI-кит с поддержкой светлой и тёмной тем (localStorage + prefers-color-scheme), строгой типизацией DefaultTheme, изоляцией цветов в теме, transient props ($...), поиском, фильтрацией по категориям, адаптивной сеткой (1 → 2 → 3 → 4 колонки) и выдвижной корзиной.

Быстрый старт
1. Установка зависимостей
```Bash
npm install
```
2. Запуск в режиме разработки
```Bash
npm run dev
```
styled-components против CSS Modules на моём проекте
В проекте "Мини-маркет" styled-components обеспечивает переключение светлой и тёмной тем через ThemeProvider и типизированный DefaultTheme, чего CSS Modules сами по себе не дают без ручной связки с CSS-переменными или data-* атрибутами на корневом элементе. Компоненты UI-кита (Button, Badge, Card, Input, Grid) получают доступ к токенам темы и динамическим состояниям ($variant, $size, $loading, $isOpen) прямо в JavaScript/TypeScript через transient props, а createGlobalStyle задаёт базовые стили и color-scheme в одном месте. CSS Modules на этом же проекте работали бы быстрее на этапе рантайма и не добавляли бы накладных расходов CSS-in-JS, а также были бы проще для статического анализа CSS. Однако при росте числа вариантов кнопок, состояний загрузки и тем в CSS Modules пришлось бы дублировать логику условий между .module.css и .tsx-файлами. Для учебного или дизайн-системного проекта с динамическими темами styled-components удобнее в плане единой точки управления токенами, тогда как для крупного продакшн-каталога с акцентом на производительность часто выигрывают CSS Modules или нативные CSS-переменные.
